# Mobile Aggregation API Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为 `figma/Makerworldarchiveuniapp` 补齐一组可直接消费的后端聚合接口，尽量复用现有 FastAPI 逻辑而不破坏桌面页接口。

**Architecture:** 在 `app/server.py` 中新增面向移动端原型的聚合接口，统一把现有图库、模型详情、归档队列、缺失文件、批量导入与整理目录配置整理为稳定响应结构。优先新增接口和映射 helper，不改现有旧接口返回，降低回归风险。

**Tech Stack:** Python, FastAPI, existing gallery/meta helpers, pytest/unittest, TestClient

# v5.8.0 更新日志

> 更新日期: 2026-04-29

## 更新概述
本次版本是一次功能增强发布，重点新增移动端 H5 前端，并将其正式接入主程序 `/h5` 路径。同时补齐了移动端模型库、归档中心、模型详情、配置下载、附件下载、收藏筛选、深色模式和 PWA 支持，便于在手机端直接浏览和管理本地模型库。

## 当前版本同步说明
- 当前版本：`v5.8.0`
- 更新说明：[`doc/logs/v5.8.0_update_log.md`](./v5.8.0_update_log.md)
- 本次重点：
  - 新增移动端 H5 页面，并接入主程序 `/h5` 路径直接访问；
  - 完成模型详情、附件下载、配置模型下载、收藏筛选、深色模式等移动端能力补齐；
  - 新增 PWA 支持，安卓与苹果可添加到主屏幕；
  - Docker 构建流程接入 `h5` 前端产物。

## 详细变更

### 新增功能
- 新增移动端 H5 前端目录 `h5/`，支持：
  - 总览页
  - 模型库
  - 归档中心
  - 模型详情
  - 通知 / 任务 / Cookie 设置
- 新增主程序 `/h5` 路由，启动 Python 主服务后可直接访问移动端页面。
- 新增模型详情页下载能力：
  - 附件下载
  - 图片附件预览
  - 配置详情中的模型文件下载
- 新增 PWA 支持：
  - `manifest.webmanifest`
  - `service worker`
  - 安卓与 iOS 主屏安装元信息
  - 主屏图标与 `apple-touch-icon`

### 优化改进
- 移动端模型库改为真实后端数据驱动，支持：
  - 来源 / 收藏夹 / 作者 / 标签真实筛选
  - 搜索条件重置
  - 收藏夹管理与即时回写
  - 归档时间 / 发布时间排序
- 移动端模型详情页优化：
  - 图文简介支持富文本和本地图片路径转换
  - 配置详情版式优化
  - 分盘信息、耗材颜色、时间和重量显示优化
- 归档中心优化：
  - 队列反馈与状态轮询
  - 最近任务显示模型名与格式化时间
- 新增移动端全局深色模式支持，并同步到：
  - 总览
  - 模型库
  - 归档中心
  - 模型详情
  - 设置页
- Docker 构建优化：
  - 新增前端构建阶段
  - 镜像内自动带上 `h5/dist`

### Bug 修复
- 修复 `/h5` 入口在无尾部 `/` 时页面空白的问题。
- 修复移动端模型图片、详情图、分盘图部分不显示的问题。
- 修复模型简介仅显示纯文本、图片不加载、视频不嵌入的问题。
- 修复配置详情页、收藏弹窗被底部导航遮挡的问题。
- 修复附件下载按钮无效的问题。
- 修复配置详情页缺少模型下载入口的问题。
- 修复设置页 Cookie 检查提示返回主页后残留显示的问题。

## 兼容性与注意事项
- 原有桌面端页面、API 和本地数据结构保持兼容，无需迁移旧数据。
- `/h5` 依赖 `h5/dist` 前端产物，若本地直接运行源码后未构建，需先执行 `npm run build`。
- Docker 部署需使用本次新镜像，旧镜像不包含 `h5` 前端产物。
- PWA 在本地 `localhost` 可测试；若要在手机上稳定安装，正式环境建议使用 `HTTPS`。
- 安卓部分浏览器若未判定为可安装站点，可能只会保存为桌面快捷方式，这属于浏览器安装策略限制。

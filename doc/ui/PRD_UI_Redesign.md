# MakerWorld Archive - UI重构产品需求文档 (PRD)

## 1. 项目背景与目标
**MakerWorld Archive (创客档案)** 是一个本地化部署的自动化管理工具，用于归档、管理和检索从 MakerWorld (拓竹3D模型库) 下载的 3D 模型及其相关元数据。

**本次设计目标**：当前前端应用（基于 Vue 3）已实现全部底层逻辑与核心功能（MVP），但在视觉表现和交互体验上相对基础。本次需要 UI 设计师在理解现有功能的基础上，**打破现有的普通布局框架**，设计一套具有极客感、现代感和极高视觉品质（Premium Style）的全新交互界面。

## 2. 目标受众与设计基调
- **目标受众**：3D 打印爱好者、极客玩家、模型整理控。
- **设计基调**：
  - **高级、通透、现代 (Modern & Premium)**：避免由于是“本地工具”就做得像传统后台。可以尝试毛玻璃 (Glassmorphism)、拟物感微渐变或 Apple/Vercel 风格的极简高级感。
  - **响应式与主题支持**：必须支持完善的 **明亮 (Light)** 和 **暗黑 (Dark)** 模式切换。
  - **微交互体验**：强调 Hover 状态、页面切换过渡、数据加载时的骨架屏或 Loading 动画的丝滑感（动效在 150ms-300ms 级别）。

---

## 3. 功能模块与交互需求明细

结合实际业务场景，系统主要包含四大核心模块：**模型库总览（首页）**、**模型详情与编辑**、**手动导入弹窗**、**控制台（系统设置与高级工具）**。

### 3.1 导航与全局布局 (Global Layout)
建议采用类似左右分栏（左侧边栏导航 + 右侧主内容区）或顶部结构布局，具体由设计师决定。
- **全局操作**：
  - 搜索框（全局模糊搜索模型名称或标签）。
  - 暗黑/浅色模式切换按钮。
  - “手动导入”快捷入口、“控制台(配置)”入口。
- **侧边栏导航 (首页关联)**：
  - **来源分组**：全部、MakerWorld 国内、MakerWorld 国际、手动导入、其他来源。
  - **筛选开关**：只看收藏、只看已打印。
  - **集合与分类**：收藏夹列表、模型分类列表。

### 3.2 模块一：模型库总览 (Model Library / Dashboard)
**功能描述**：用于全局展示和管理本地已归档的 3D 模型集合。
- **数据展示**：
  - **总计状态**：顶部显示当前筛选条件下的总模型数量（如“共 262 个模型”）。
  - **核心部件：模型卡片网格 (默认模式)**。单张卡片需容纳的高密度信息：
    - **封面大图**（多色版本/特色标签以 Overlay 角标形式悬浮显示）。
    - **标题与作者**。
    - **五维数据展示区**：点赞数 (Thumbs Up)、收藏数 (Star)、打印数 (Prints)、下载量 (Downloads)。
    - **时间线**：发布/更新日期、本地归档日期。
    - **卡片快捷动作条 (底部/悬浮)**：浏览器打开源链接、加入/取消收藏、标记为已打印、删除模型。
  - **精简模式 (Compact Mode)**：只显示模型封面图和模型名称，提供与默认模式的切换按钮。
- **操作与过滤区 (Action Bar)**：
  - **排序控件**：下拉菜单支持按下载量、按收藏数、按发布时间、按采集时间（支持正序/倒序）排列。
  - **常用按钮区**：“刷新索引”按钮。
  - **视图模式切换**：默认视觉模式 vs 简洁模式按钮。
  - **多选批量操作 (Batch Select)**：点击“多选”按钮后，卡片上浮现复选框，可进行批量选中，执行底部或顶部弹出的批量动作面板（如下载、删除、并重点提供**批量收藏/取消收藏**功能）。
- **异常/空状态**：
  - 数据加载时的骨架屏 (Skeleton)。空数据状态的插画。

### 3.3 模块二：模型详情 (Model Detail)
**功能描述**：查看特定模型的所有元数据、配置文件、相册图库，并支持编辑与追加内容。
**交互要求**：页面信息非常丰富，可以考虑双栏抽屉式布局、沉浸式全屏模态框，或独立的富交互内页。
- **左侧/顶部 - 高清图库 (Gallery)**：
  - 占据较大视觉比重的主图区，支持左右切换。
  - 底部带有多张缩略图的横向轮播条 (Carousel)。
- **右侧/主信息面板 - 数据与元数据**：
  - **基础信息**：标题大字号、作者名及头像、来源标记 (标注具体属于哪个外网或本地导入)、采集日期。
  - **内联编辑功能**：允许直接点击修改标题、作者，以及**特有的“来源标记”编辑功能**，方便用户随时更正模型来源信息。
  - **聚合数据指标**：醒目展示下载数、点赞数、打印数、综合评分/星标、浏览量。
  - **标签 Tags**：平铺排列的特征标签。
  - **核心部件：打印配置列表 (Print Profiles)**：
    - 允许用户手动或自动“添加打印配置”（需要提供专门的添加交互区，如悬浮窗口或明显按钮供操作）。
    - 每条配置卡片展示：配置名称尺寸、打印盘数 (Plates)、耗时估算 (如 13.6h)、耗材总重量 (如 247g)。
    - **耗材详情明细**：颜色圆点 + 材质 + 重量（如 PLA 47g、PETG 15g）。
    - 每个配置卡片附带自己的两三张层切图或渲染图小样。
    - **配置操作按钮区**：每条配置右下角提供直观的 “详情”、“打印”、“下载” 快捷动作按钮。
    - **配置分盘详情 (Plates Detail)**：点击“详情”按钮后，弹出悬浮窗或展开区，展示该配置的具体分盘清单（如“盘1：PETG 61g 1.4h”，“盘2：PETG 31g 43.9min”）。
- **底部附加区块**：
  - **模型简介**：长文本/富文本描述区。
  - **打印成品 (Makes)**：支持上传图片或浏览他人打印成品的画廊。
  - **附件文件 (Attachments)**：罗列 3MF、STL、PDF 等文件，支持本地上传。
  - *(这些区域可以做成 Tab 切换或长滚动)*

### 3.4 模块三：手动导入弹窗 (Manual Import Modal)
**功能描述**：用于手动录入不在主流平台上的模型，表单结构较复杂，建议设计为沉浸式全屏的 Modal 或分步向导体验。
- **智能识别区**：上传 3MF 文件的快捷组件，包含读取按钮和“批量目录导入”。
- **基础输入流**：
  - 文本框：模型名称、模型地址、模型来源。
  - 富文本编辑器：涵盖粗体、斜体、列表、引用和清除格式操作的模型介绍框。
  - 标签输入框：空格分隔。
- **文件上传流**：可以设计美观的 Drag & Drop 拖拽上传区块。
  - 封面图片 (单张)。
  - 设计图片 (多选大图)。
  - 实例文件 (多 3MF 文件添加，每个文件独立识别信息)。
  - 附件文件 (通用格式支持)。
- **底部动作**：保存/取消。

### 3.5 模块四：控制台与系统设置 (Console & Settings)
**功能描述**：多 Tab 切换的高级系统后台（建议做成独立页面布局），主要包含以下标签页：
- **配置信息 (Cookies & Core)**：
  - 设置用于采集的国内及国际平台 Cookie。
  - 设计美观的卡片化 Cookie 列表：展示正常/失效状态绿红点，API 成功/失败统计，支持“+ 添加”、“预览”、“删除”单条配置。
- **模型归档 (Manual Archive Tool)**：
  - 单独成页的一个核心工具栏。
  - 一个醒目的长输入框用于输入 MakerWorld 原链接。
  - “开始归档”的主按钮，及操作帮助说明卡片。
- **缺失记录 (Error Logs)**：用于记录异常和下载失败的任务日志。
- **通知配置 (Notifications)**：
  - **Telegram 通知**：总开关 Toggle。Bot Token 输入、Chat ID 输入、在线地址前缀配置。提供“测试连接”和“保存”按钮。
- **其他功能 (Advanced Utils)**：
  - 高级自动化脚本面板：包括“历史归档维护”(一键更新索引)；“本地批量导入监控设置”(启停开关、监控目录多行输入、扫描间隔时间设置、推送汇总汇总开关)；“本地 3MF 整理脚本”(映射目录配置、移动/复制清理模式)。

## 4. 给 UI 设计师的特别提示
1. **打破固化思维**：本文档只是列举了“有什么功能”，**不代表你要按照传统后台的 CRUD 界面来排版**。请发挥才华，对于拥有图库和大量复杂数字指标的【模型详情页】，我们尤其鼓励向 Apple App Store / 现代主机游戏 UI 参考那种层级分明的排版。
2. **图标系统**：请考虑使用一套一致的线性或面性现代图标库（如 Lucide / Phosphor）。并在关键数据（如下载量、点赞量）上辅以清晰的视觉色彩权重。
3. **真实感预览**：在设计卡片或详情页时，请务必使用高质量的真实 3D 打印模型照片作为占位图，以便更好地呈现最终落地的质感和卡片的视觉张力。
4. **交付物要求**：推荐使用 Figma，交付内容应包含关键页面的 Light / Dark 模式，并针对卡片交互、多选批量操作状态、Modal 弹窗反馈给出原型演示或视觉标注。
